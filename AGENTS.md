## Agent skills

### Issue tracker

Issues live as GitHub issues in kyoduke/detran-practice, driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Design

UI design lives in `pencil.pen` at the repo root (edited via the `pencil` MCP tools, never Read/Grep — the file is encrypted). When a ticket has a visual deliverable, it names the frame(s) to consult; otherwise ask before guessing a look.
