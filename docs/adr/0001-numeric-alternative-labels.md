# Numeric alternative labels instead of letters

The official Detran RJ exam presents alternatives as A–D, but we label them 1–4 on screen and map keyboard keys 1–4 by position. We chose numbers because they sit contiguously on the keyboard (letters are scattered), and we align the on-screen labels to the keys so the mapping is self-evident.

## Considered Options

- **Letters A–D on screen, digits 1–4 on keyboard**: rejected. Discoverability breaks — the screen shows A–D but the user types 1–4, forcing a position-to-letter translation.
- **Numbers 1–4 everywhere**: chosen. The training screen diverges from the official exam's A–D format, but ergonomics and discoverability win.
